

# 🎓 Student 360° — Performance & Insight Analytics

> **Turning student data into actionable insights — one dashboard, five perspectives.**

An interactive **Power BI Student Analytics Dashboard** designed to provide a complete 360° view of student performance by combining **academic achievement, attendance, behavior, engagement, and risk analysis** into one interactive reporting solution.

---

## ✨ What Makes This Dashboard Different?

Instead of analyzing student information through separate reports, this project connects multiple perspectives into one analytical experience:

**📚 Academic Performance → 🕒 Attendance → 🧠 Behavior → ⚠️ Risk → 🎓 Student 360° Profile**

The dashboard allows users to move from an overall performance overview to detailed student-level insights using interactive Power BI features.

## 🚀 Interactive Features

### 🔍 Dynamic Slicers

Filter the dashboard using:

`Gender` • `Class` • `Section` • `Subject` • `Term` • `Exam Type` • `Student`

### ↗️ Drill-Through

Navigate from overall analysis to a detailed **individual student profile**.

### 💬 Custom Tooltips

Hover over visual elements to view additional contextual insights without leaving the current page.

### 🔄 Cross-Filtering

Selecting a visual element dynamically updates related charts, KPIs, tables, and matrices.

### 📱 Mobile Layout

The dashboard includes a mobile-friendly layout for a better viewing experience on smaller screens.
